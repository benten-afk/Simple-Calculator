# 🧮 Simple Calculator

A simple command-line calculator built with **Python** to practice programming fundamentals, user input, functions, and basic arithmetic operations.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* ⌨️ User input through the terminal
* ⚠️ Basic handling of invalid operations

## 🛠️ Built With

* 🐍 Python

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/benten-afk/Simple-Calculator.git
```

### 2. Open the project

```bash
cd Simple-Calculator
```

### 3. Run the calculator

```bash
python calculator.py
```

> If your Python file has a different name, replace `calculator.py` with the actual filename.
